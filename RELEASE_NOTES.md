**Download `Mutagen.exe`** (portable: just run it) or the `Mutagen_…_x64-setup.exe` installer.

About 6 MB, down from 358 MB. It uses the WebView2 runtime that comes with Windows 10/11.

**New in 1.1.0**
- Number boxes use app-styled arrows instead of the white browser spinners
- Artifacts: compact icon grid. Click a bar to set the level; a lower bar lowers it
- Hero swap: drag a portrait onto *Current character* (clicking still works)

Close the game before saving. Backups are in `%LOCALAPPDATA%\Mutagen\backups`.
